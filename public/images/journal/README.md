# Journal cover images

Drop placeholder/cover photos here (Istanbul, sea views, architecture, etc.).
Each article looks for a file **named after its English slug**, in any of these
extensions (first match wins, in this order): `.avif`, `.webp`, `.jpg`,
`.jpeg`, `.png`.

If a file is missing, the article shows a muted placeholder block — no broken
image. Drop a file in and it appears on the next render/build (no code change).

Recommended: landscape **3:2**, ~1600×1067px or larger, optimized.

| Article (EN) | Expected filename |
|---|---|
| On colour and concrete | `on-colour-and-concrete.jpg` |
| A studio visit, in three sounds | `a-studio-visit-in-three-sounds.jpg` |
| Notes on an empty gallery | `notes-on-an-empty-gallery.jpg` |
| The weight of a white wall | `the-weight-of-a-white-wall.jpg` |
| The architecture of a harbour | `the-architecture-of-a-harbour.jpg` |

(Filenames use the English slug regardless of viewing language; the same image
serves both `/en/blog/...` and `/tr/blog/...`.)
